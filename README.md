# TutorMark (과외·멘토링 사진 과제 및 실시간 첨삭 피드백 시스템)
> **DB & 파일 스토리지: Supabase (PostgreSQL & Storage) 완벽 지원**

줌(Zoom) 원격 과외 및 멘토링 수업 시 학생이 시험지나 책을 사진으로 찍어 올리고, 선생님이 이를 확대하여 마우스로 다양한 색상의 펜/형광펜 첨삭을 하거나 키보드로 글자를 입력한 후, 댓글 형태로 피드백을 저장하고 확인할 수 있는 웹 애플리케이션입니다.

---

## ⚡ Supabase 연동 방법 (3분 완성)

TutorMark는 **Supabase 클라우드 데이터베이스(PostgreSQL) 및 스토리지(Storage)**를 기본 지원합니다.

### 1단계: Supabase 프로젝트 생성 및 SQL 실행
1. [Supabase 공식 홈페이지](https://supabase.com)에 로그인 후 새 프로젝트를 생성합니다.
2. 좌측 메뉴의 **SQL Editor**로 이동합니다.
3. 프로젝트 내의 **[`supabase_schema.sql`](file:///c:/Users/박대현/Downloads/학생이%20사진%20찍어%20올리고%20그%20이미지%20위에%20마우스로%20그림그리거나%20키보드로%20글자를%20치는/supabase_schema.sql)** 파일의 내용을 복사하여 붙여넣고 **Run**을 실행합니다.

### 2단계: Storage 버킷 생성
1. 좌측 메뉴의 **Storage**로 이동하여 **New Bucket**을 클릭합니다.
2. 버킷 이름을 **`tutormark-files`** 로 입력하고, **Public bucket** 옵션을 활성화(ON)합니다.

### 3단계: `.env` 파일에 키 입력
1. 좌측 메뉴의 **Project Settings -> API**에서 `Project URL`과 `anon public` 키를 확인합니다.
2. 프로젝트 루트의 **`.env`** 파일에 입력합니다:
```env
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_KEY=your-supabase-anon-or-service-key
SUPABASE_BUCKET=tutormark-files
```

*(참고: `.env`를 설정하지 않은 경우에도 로컬 SQLite 및 로컬 저장소로 자동 구동됩니다.)*

### 교사 모드 PIN 변경 (선택)

기본 PIN은 `1234`입니다. `.env`에 아래 값을 넣으면 변경할 수 있습니다 (쉼표로 여러 개 지정 가능):

```env

```

## 🚀 빠른 시작 (실행 방법)

### 1. 윈도우 원클릭 실행
폴더 내의 **`run.bat`** 파일을 더블 클릭하면 필요한 패키지 확인 후 자동으로 웹 브라우저(`http://localhost:8000`)가 열립니다.

### 2. 터미널에서 직접 실행
```bash
# 1. 의존성 설치
python -m pip install -r requirements.txt

# 2. 서버 실행
python app.py
```
브라우저에서 **`http://localhost:8000`** 접속.

코드를 수정한 뒤 전체 기능이 정상인지 실제 브라우저로 한 번에 확인할 수 있습니다.

```bash
python -m pip install playwright requests
python -m playwright install chromium
python verify_e2e.py
```

임시 서버를 로컬 SQLite 모드로 띄워 **사진 업로드 → 캔버스 첨삭(펜/글자/지우개/되돌리기)
→ 페이지 넘김 → 저장 → 댓글 확인 → 삭제**까지 59개 항목을 점검하고,
테스트로 만든 데이터는 스스로 정리합니다. (Supabase 데이터는 건드리지 않습니다.)

## 📱 주요 기능 안내

### 1. 학생용 모드 (스마트폰 / 태블릿 / PC)
- **학생 프로필 간편 선택**: 민수, 서연 등 학생 프로필 선택 및 새 학생 추가
- **스마트폰 카메라 연동 사진 업로드**: 스마트폰 카메라로 문제집이나 시험지를 바로 촬영하여 고화질 업로드 (EXIF 회전 자동 보정 및 Supabase 스토리지 자동 저장)
  - 아이폰 **HEIC** 사진은 `pillow-heif` 패키지로 자동 변환됩니다. (`requirements.txt`에 포함, 설치 실패 시 안내 메시지 표시)
  - 사진 1장당 최대 25MB, 한 번에 최대 30장
- **과제 정보 & 질문 메모**: 과목(수학, 영어, 국어 등), 범위, 헷갈렸던 부분 질문 메모 작성
- **선생님 첨삭 피드백 확인**: 선생님이 첨삭한 고화질 이미지와 코멘트를 댓글 형태로 열람 및 다운로드

### 2. 교사용 모드 (PC / Zoom 화면 공유 최적화)
- **대시보드 통계**: 미첨삭 대기 과제, 첨삭 완료 과제, 학생별 과제 현황을 한눈에 파악
- **인터랙티브 고성능 캔버스 첨삭 에디터**:
  - **줌 & 팬 (Pan & Zoom)**: 마우스 휠로 자유로운 확대/축소, Space키 + 드래그 또는 손도구로 부드러운 화면 이동
  - **다양한 펜 도구**: 빨강, 파랑, 초록, 노랑 등 다양한 색상 지원, 선 굵기 조절, 반투명 형광펜 모드
  - **키보드 글자 타이핑 (Text Annotation)**: 원하는 위치를 클릭하고 바로 타이핑하여 가독성 높은 텍스트 주석 추가 (글자 크기, 색상 조절)
  - **채점 기호 스탬프**: ⭕(정답), ❌(오답), ✔️(확인), ➡️(화살표), 🔲(사각형), ⚪(원), 📏(직선)
  - **지우개 및 되돌리기**: 실행 취소(Ctrl+Z / Ctrl+Shift+Z), 다시 실행(Ctrl+Y), 개별 지우개, 전체 초기화
    - 되돌리기는 **스냅샷 방식**이라 펜/도형뿐 아니라 **지우개와 전체 초기화까지 모두 되돌릴 수 있습니다.**
  - **태블릿 지원**: 두 손가락 핀치 확대/축소 및 화면 이동
  - **여러 장 연속 첨삭**: 페이지를 넘겨도 각 페이지의 첨삭 내용과 총평이 그대로 유지되며,
    저장 시 자동으로 다음 페이지로 넘어가 마지막 장에서 에디터가 닫힙니다.
  - **재첨삭(이어서 수정)**: 이미 첨삭한 과제를 다시 열면 **이전 첨삭 획이 그대로 복원**되어
    처음부터 다시 그릴 필요 없이 이어서 수정할 수 있습니다.
  - **안전장치**: 저장하지 않은 첨삭이 있는 상태로 닫거나 새로고침하면 경고가 뜹니다.
- **댓글형 피드백 저장**:
  - 원본 사진 해상도에 맞춰 캔버스 첨삭 레이어를 고화질로 결합하여 Supabase 스토리지 및 DB에 저장
  - 선생님 총평 코멘트와 함께 제출글 아래 댓글로 자동 등록 및 상태 '첨삭 완료'로 변경
